🔗 2. Shareable Assessment + QR

Entry: /?page=assessment or /assessment

Shareable URL: /?page=assessment

Pretty URL /assessment via SPA fallback. QR opens directly to assessment landing.

How to share:
• In person: show QR
• LinkedIn: download + post
• Email: paste link + QR
• Presentation: full-screen QR
• Print: A4, poster, handout
• Messages: WhatsApp/SMS

Privacy: No admin exposed. Each learner own trialId. Independent session.
Open Assessment Landing → Download QR
Learner flow — 10 steps
  1. Open shared link or scan QR
  2. See short explanation
  3. Start assessment
  4. Answer 20 Q adaptive M1→M5
  5. Receive varied questions (5,100+ variants)
  6. Complete assessment
  7. Receive skill profile (strengths ≥75%, weaknesses <60%)
  8. See strengths/weaknesses per category
  9. See suggested starting point M1→5
  10. Continue into full learning experience
✓ Independent session per learner
✓ No admin data exposed
✓ Questions varied via hash(seed)
✓ Results saved per trialId
