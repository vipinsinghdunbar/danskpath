Danish Design for DanskPath
Clean. Functional. Hygge.

Picked Danish Design style — no AI-generated humans. All illustrations are geometric, line art, abstract landscapes, icons, Copenhagen houses, bicycles, windmills, candles, typography. Focus on transitions & animations — spring, stagger, waveform, progress.

🇩🇰 1. Functional Minimalism

Every element has purpose. No decoration for decoration. Whitespace, grid, typography hierarchy.

🪵 2. Natural & Hygge

Cream paper, wood texture, soft shadows, warm light. Candle, bicycle, houses — no people, but human presence felt.

🔤 3. Typography First

Outfit bold for Danish headlines æøå, Inter for body. Large type 40-56px hero, 14px details.

⚙️ 4. No AI Humans

Zero AI-generated people. Use line icons, geometric avatars, abstract landscapes, symbols. Real photos only if consensual.

🎞️ 5. Transitions Matter

Spring 300ms ease-out, stagger 60ms, progress morph, waveform sync, button press scale 0.98, check pop.

♿ 6. Accessible iOS

48-56px touch, 4.5:1 contrast, VoiceOver Danish labels, haptics, safe areas, PWA installable.

5b Dashboard Transition — Progress & Cards Stagger

Transition SpecStagger 60msNo Humans

Concept: Shows dashboard elements animating — streak card, circular progress, path nodes, lesson cards. Demonstrates stagger 60ms, spring, progress fill. This is used for all app screens — elements enter with subtle motion, not just fade.

✅ Transition Principles
  • Stagger: each card 60ms delay — feels natural, not robotic
  • Spring: stiffness 300 damping 30 — Danish smooth, not bouncy
  • Progress: circular + linear both animate 1s
🔧 Implementation
  • Container: motion.div variants staggerChildren 0.06
  • Item: initial y:12 opacity:0 → y:0 opacity:1 spring
  • Path: motion.path initial pathLength:0 → 1 duration 2s
Code:
const container = {hidden:{},show:{transition:{staggerChildren:0.06}}}
const item = {hidden:{y:12,opacity:0},show:{y:0,opacity:1,transition:{type:"spring",stiffness:300,damping:30}}}
<motion.div variants={container} initial="hidden" animate="show">{items.map(i=><motion.div variants={item}>...)}</motion.div>

TRANSITIONS & ANIMATIONS — SPEC

✦ Danish Motion — Functional, Not Decorative

Spring 300msStagger 60msPress 0.98

Danish Motion Principles: Motion should be functional — show hierarchy, feedback, causality. No bouncy overshoot. Use spring stiffness 300 damping 30 — smooth, calm, like Danish furniture drawers.

🎞️ Page Transitions
  • Slide: new page x: 20→0 opacity 0→1 300ms spring, old page x:0→-20 opacity 1→0 200ms
  • Fade: for modals — backdrop opacity 0→1 200ms, content scale 0.96→1 300ms spring
  • Shared: logo, tab bar stay, content morphs with layoutId
🃏 Card & List
  • Stagger: container staggerChildren 0.06, item y:12→0 opacity 0→1 spring 300ms
  • Hover: lift y:-2 shadow md 200ms, press scale 0.98 100ms
  • Check: pop scale 0→1.2→1 400ms + confetti
📊 Progress & Charts
  • Circular: strokeDashoffset 0→68% 1s spring, number count up 0→68 1s
  • Bar: height 0→value% 800ms spring stagger 80ms per bar
  • Radar: pathLength 0→1 1.2s ease-out, fill opacity 0→0.2 600ms delay
  • Waveform: 32 bars scaleY 0.3→1 with audio time, delay index*20ms
🔘 Buttons & Inputs
  • Button: hover lift 2px, press scale 0.97, focus ring sage 2px 200ms
  • Input: focus border sage 2px, label float up scale 0.85 200ms
  • Tab: active pill slides with layoutId "activeTab" 300ms spring
  • Option: select scale 0.98→1 + bg blue 200ms + haptic light
Implementation — Framer Motion:
import { motion, AnimatePresence } from "framer-motion"

const item = {hidden:{y:12,opacity:0},show:{y:0,opacity:1,transition:{type:"spring",stiffness:300,damping:30}}}

// Button press

// Progress
<motion.circle initial={{pathLength:0}} animate={{pathLength:0.68}} transition={{duration:1,type:"spring"}} />
