  • Fly.io: Stockholm region (30ms from Copenhagen)
1. git init && git add . && git commit -m "deploy"
2. Create repo github.com/new → danskpath
3. git remote add origin https://github.com/YOU/danskpath.git
4. git push -u origin main
5. dashboard.render.com/blueprint/new → Connect repo → Apply
6. Public URL: https://danskpath.onrender.com
